# Sounds

`flap.mp3`, `point.mp3` and `die.mp3` are generated with ElevenLabs sound effects from the prompts in
`scripts/render-sounds.mjs` (run it to regenerate; delete a file first to re-render it). They replace the earlier
`*-101soundboards.mp3` clips, whose source and licence were never recorded. Nothing in this folder is third-party audio.
